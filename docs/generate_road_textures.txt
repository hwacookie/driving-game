The API shape, both of these cost me a dead 2-minute poll before I read them:

- `POST /prompt {"prompt":<graph>,"outputs":[{"node":"9","type":"image"}]}` answers
  `{"prompt_id":…,"number":…,"node_errors":{}}` - accepted, not the result.
- `/history` returns a dict **keyed by prompt_id**; `/history/<prompt_id>` wraps
  the same entry one level deeper (`{"<pid>": {prompt,outputs,status,meta}}`), so
  `entry["outputs"]` is `{"<node id>": {"images":[{filename,subfolder,type}]}}`.
  While a job is pending `/history` has no key for it and the entry's `outputs`
  is `null` - an empty answer is only a fact about that shape.
- Fetch the file: `GET /view?filename=<fn>&subfolder=&type=output`.
